Real recordings for the ten ambience sounds go here.

  rain.mp3  thunder.mp3  waves.mp3  wind.mp3  fire.mp3
  birds.mp3  crickets.mp3  coffee-shop.mp3  singing-bowl.mp3  white-noise.mp3

(.ogg, .wav, .flac, .m4a, .aac and .opus work too.) Any slot without a file keeps its generated sound.
Aim for 1 to 5 minutes each, recorded steadily with no sudden bangs, so the loop does not stand out.
Automatic download from freesound.org:  FREESOUND_TOKEN=... npm run sounds:fetch
Full guide: docs/SOUNDS.md
