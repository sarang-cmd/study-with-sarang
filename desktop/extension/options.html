Study with Sarang Helper

A small helper for the Study with Sarang desktop app. It tells the app which website is open in this browser, so drift detection can tell a lecture from a distraction. It works on this computer only.

Status

Checking...

Set up in two steps

  1. In Study with Sarang open Settings, Drift detection, Browser helper, switch it on and press Pair the extension.
  2. Come back here and press Connect to the app. That is all. You do not need to copy any code.
You need the desktop app for Windows or macOS. It is free at sarang-md.vercel.app/study-with-sarang/downloads.

Settings

Advanced: port and pairing code

Only needed if you changed the port in the app or want to paste the code by hand.

What it sends, and where

The website name (for example youtube.com), the browser name, and the page title if you allow it, to 127.0.0.1, which is this computer. Never to the internet. Private windows are never reported. The helper reads no page content and keeps no history.

Updates

Checking for a newer helper...

If you loaded the helper from the folder the app keeps for you, the app refreshes that folder after each update. Restart the browser, or press the reload arrow on the extensions page, to pick it up.
